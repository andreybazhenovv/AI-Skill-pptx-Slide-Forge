## 1. Исходные вводные (2026-10-29)

- **Задача**: из русскоязычного конспекта `data.md` (тема «Spec-Driven Development
  с AI-агентами», в исходнике — план на 24 слайда) собрать презентацию, а на её
  основе — **переиспользуемый AI-скилл** (формат Agent Skills), который строит
  премиальные презентации программно.
- **Пользовательские вводные**: стиль задаётся JSON-спекой (первая —
  «NovaPay — Liquid Electric Blue»); примеры и документация — на английском;
  лицензия MIT; репозиторий — `pptx-AI-Slide-Forge` с git.
- **Среда**: macOS; `python-pptx` 1.0.2 + `Pillow` 11.2.1 + `numpy` (без
  `aggdraw`); рендер-QA — Keynote по AppleScript (PowerPoint-экспорт молча не
  работает — задокументировано); шрифт Helvetica Neue (Latin + Cyrillic).
- **Процесс разработки**: сабагент-верификатор + визуальная инспекция рендеров,
  частые промежуточные коммиты (запрошено пользователем).

## 2. Ключевые архитектурные решения

| # | Решение | Почему |
|---|---|---|
| D1 | **Скилл, а не разовый скрипт**: `SKILL.md` с гейт-воркфлоу + движки отдельно от контента | переиспользуемость: новый стиль = новые токены + конфиг, без правки кода |
| D2 | **Фоны — процедурные** (numpy + PIL): liquid-ribbons, ribbed metal, shape-слои | детерминизм, без стока и внешних сервисов; luminance-гейты на текстовых зонах |
| D3 | **Стиль — JSON-спека, source of truth**: токены → движок → паттерны | новый стиль = новые данные; спека версионируется вместе со скиллом |
| D4 | **QA-конвейер**: geometry lint + markitdown text QA + Keynote render → визуальная инспекция каждого слайда | «it should work» не принимается — только проверенный результат |
| D5 | **Демки — данные, не код**: каждый стиль = `textures_config.py` + мини-`build_demo.py` | примеры служат тестами движка и документацией одновременно |

## 4. Дефекты и ловушки (через что прошли)

### 4.1 Движок и рендер

- **Wireframe-меш «исчез»**: `ImageDraw` **заменяет** пиксели, а не блендит —
  полигон следующей полосы перезаписал только что нарисованные линии. Fix:
  два прохода (все полигоны, затем все штроки) + RGBA-оверлей с прозрачной
  окклюзией. Урок задокументирован в `background-engine.md`.
- **«Тонкие неоновые линии» вместо объёмных лент**: первая итерация ember-фонов.
  Fix: ширина ленты ×1.5, тело ленты насыщеннее (floor 0.62), спекуляры уже
  (σ 0.085). Правило внесено в failure-modes.
- **Светлая тема «ужасная» (v1)**: vignette-затемнение — инструмент тёмных тем —
  сминал белый фон в тёмно-серые края с белыми «струями». Fix: vignette ≈ 0
  для светлых стилей, акцент — на векторные композиции и деликатные заливки.
- **Кэш импорта Keynote**: повторный `open` того же пути может отдать старый
  импортированный документ → экспорт устаревшего контента. Fix: рендер через
  **уникальное имя файла** (копия pptx в новый путь) + `pkill Keynote` перед
  экспортом. Задокументировано в `qa-and-toolchain.md`.

### 4.2 Окружение агента

- **read_file replay trap**: повторное `read_file` того же пути возвращает
  кэшированный старый результат, даже если файл на диске изменился. В цикле
  fix → rebuild → render → «прочитай рендер» это даёт ложный дебаг («фикс не
  сработал» на исправленном файле). Fix: читать через **новый путь**
  (`/tmp/verify-fresh/<новое-имя>.png`). Урок сохранён в memory агента.

### 4.3 Контент и типографика

- Caps-лейблы с tracking переносились при ширине «впритык» → буфер ≥ 15%.
- Дефисы `-` вместо тире `—` в копи (Ember: 3 места) — правило: типографские
  тире и кавычки в копи, дефис только в составных словах.
- Контраст брендинга на цветной заливке (белый лейбл на royal-blue) — правило:
  на цветных слайдах бренд-текст белый.

## 5. Верификация

- **Внешний аудит (субагент-верификатор, без контекста сессии)**:
  `PASS WITH FINDINGS` — ядро живое, воркфлоу воспроизводится агентом с нуля
  end-to-end (свой конфиг → фон → сборка → рендер → qa_check). 11 замечаний:
  doc-хвосты (пути в примерах, имена файлов, устаревшие числа), schema
  (единообразие identity-ключей стилей), robustness (graceful-ошибки, assert →
  raise), nit (семплы ассетов). Статус закрытия — см. §6.
- **Внутренний QA каждого стиля**: geometry lint, luminance-отчёт по текстовым
  зонам, markitdown-проверка текста, визуальная инспекция всех слайдов через
  Keynote-рендер, фикс-циклы до чистого прогона.
